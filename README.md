# 📊 Retail Sales Analysis

## 📌 Project Overview

This project analyzes retail sales data using **MySQL and Microsoft Excel** to identify sales trends, top-performing products, customer performance, regional performance, and payment preferences.

The project demonstrates practical data analysis skills including SQL querying, data aggregation, business metrics, and dashboard creation.

## 🎯 Project Objectives

- Analyze overall retail sales performance
- Identify top-performing products and categories
- Compare sales across different regions
- Analyze monthly sales trends
- Understand customer purchasing performance
- Analyze payment mode preferences
- Calculate Average Order Value (AOV)
- Build an Excel dashboard to visualize key insights

## 🛠️ Tools & Technologies

- MySQL
- SQL
- Microsoft Excel
- PivotTables
- Excel Charts
- Data Cleaning & Analysis

## 📂 Dataset

The dataset contains **44 retail sales transactions** with the following columns:

| Column | Description |
|---|---|
| Order_ID | Unique order identifier |
| Order_Date | Date of the order |
| Customer | Customer/store name |
| Product | Product purchased |
| Category | Product category |
| Quantity | Quantity purchased |
| Unit_Price | Price per unit |
| Total_Sales | Total sales value |
| Region | Sales region |
| Payment_Mode | Payment method |

## 🔍 SQL Analysis

The following analyses were performed using MySQL:

### 1. Overall Sales Performance
Calculated total orders, total quantity, total sales, and Average Order Value.

### 2. Sales by Category
Compared sales performance across different product categories.

### 3. Sales by Region
Identified the regions generating the highest sales.

### 4. Monthly Sales Trend
Analyzed sales performance across months in 2025.

### 5. Top 5 Products
Identified the products generating the highest sales.

### 6. Payment Mode Analysis
Compared order volume and sales across different payment methods.

### 7. Average Order Value by Region
Calculated and compared AOV across regions.

### 8. Top 5 Customers
Identified customers contributing the highest sales.

## 💡 Key Business Insights

- **North** was the highest-performing region with sales of **₹27,205**.
- **Beverages** generated the highest category sales at **₹6,600**.
- **Aashirvaad Atta 5kg** was the top-selling product with **₹12,600** in sales.
- **May 2025** recorded the highest monthly sales at **₹5,410**.
- **UPI** was the most frequently used payment method with **22 orders** and **₹29,380** in sales.
- **West** had the highest regional Average Order Value at **₹1,466.36**.
- **City Supermarket** was the highest-selling customer with **₹6,590** in sales.
